- [ ] `public/musiqa/munojot.jpg` + `public/audio/musiqa/munojot.mp3` + `munojot.lrc` — Munojot
- [ ] `public/musiqa/yallama-yorim.jpg` + `.mp3` + `.lrc` — Yallama Yorim
- [ ] `public/musiqa/ushshoq.jpg` + `.mp3` + `.lrc` — Ushshoq
- [ ] `public/musiqa/lazgi.jpg` + `.mp3` + `.lrc` — Xorazm Lazgi
- [ ] `public/musiqa/andijon-polkasi.jpg` + `.mp3` + `.lrc` — Andijon Polkasi
- [ ] `public/musiqa/buxoro-tanovari.jpg` + `.mp3` + `.lrc` — Tanovar

The site falls back to the **YouTube embed** (`youtubeId` field) for audio playback,
so the missing `.mp3`s are not breaking the karaoke UI — they're just the
preferred local source for offline / fast playback.

**Format notes**:
- `.mp3` — 128–192 kbps is plenty for vocal-heavy maqom; keep file size under ~5 MB each so they cache nicely.
- `.lrc` — the standard timed-lyrics format used by the karaoke component. One line per timestamp:
  ```
  [00:12.34]First line of lyrics
  [00:18.50]Second line
  ```
- `.jpg` — square or 4:3, ~600–800 px wide. The card is small.

## How to drop new files in

1. Put each file at its target path (paths in this doc are relative to the project root).
2. Filename must match exactly — the JSON already references it by that name.
3. No restart, no rebuild needed for `public/` files in dev mode — Vite serves them directly.
4. For prod (the VPS), just `scp` the file into the matching `dist/...` folder or
   re-run `npm run build && scp -r dist/* meros@91.210.106.168:/srv/meros/dist/`.
